1️⃣  AGREGAR MÁQUINA NUEVA (4 pasos)
   ┌─────────────────────────────────────────────────────────────────────┐
   │ Nuevo Equipo:    .venv\Scripts\python renewal_license.py --myid    │
   │                  → Copiar Machine ID: ABC123DEF456...               │
   │                                                                     │
   │ Admin:           .venv\Scripts\python register_equipment.py register │
   │                  → Genera licencia automáticamente                  │
   │                  → Copiar CPRO-...                                 │
   │                                                                     │
   │ Nuevo Equipo:    .venv\Scripts\python activar_licencia.py --key     │
   │                  → Activar licencia                                 │
   │                                                                     │
   │ Verificar:       .venv\Scripts\python -c "import license_manager"  │
   │                  → {'valid': True, 'days_left': 364}               │
   └─────────────────────────────────────────────────────────────────────┘

2️⃣  RENOVAR LICENCIA ANUALMENTE (1 paso)
   ┌─────────────────────────────────────────────────────────────────────┐
   │ Automático:      Windows Task Scheduler (configurado)              │
   │                  → Cada 1 de agosto a las 09:00 AM                │
   │                                                                     │
   │ Manual:          .venv\Scripts\python renewal_license.py --auto    │
   │                  → Ejecutar cuando quieras                          │
   │                                                                     │
   │ Resultado:       Licencia renovada con +365 días                   │
   │                  .env actualizado                                  │
   │                  equipos_registro.json actualizado                 │
   └─────────────────────────────────────────────────────────────────────┘

3️⃣  CONSULTAR ESTADO (3 opciones)
   ┌─────────────────────────────────────────────────────────────────────┐

   │                                                                     │
